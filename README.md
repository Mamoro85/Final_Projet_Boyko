# Планировщик задач (Task Scheduler)

## Описание проекта

Это веб-приложение для управления задачами с поддержкой повторяющихся событий. Проект представляет собой полнофункциональный планировщик задач с веб-интерфейсом и REST API.

## Технологии

- **Backend**: Go
- **База данных**: SQLite
- **Frontend**: HTML, CSS, JavaScript
- **Тестирование**: testify

## Инструкция по запуску

### Локальный запуск

2. **Клонируйте репозиторий и перейдите в директорию проекта:**
   ```bash
   cd Final_Projet_Boyko
   ```

3. **Установите зависимости:**
   ```bash
   go mod tidy
   ```

4. **Запустите сервер:**
   ```bash
   go run main.go
   ```

5. **Откройте браузер и перейдите по адресу:**
   ```
   http://localhost:7540
   ```

### Переменные окружения

Вы можете настроить порт сервера через переменную окружения:
```bash
export TODO_PORT=8080
go run main.go
```

По умолчанию сервер запускается на порту **7540**.

## Инструкция по запуску тестов

### Запуск всех тестов:
```bash
go test ./tests
```

### Запуск конкретных тестов:
```bash
# Тест добавления задач
go test -run ^TestAddTask$ ./tests

# Тест получения задач
go test -run ^TestTasks$ ./tests

# Тест редактирования задач
go test -run ^TestTask$ ./tests

# Тест выполнения задач
go test -run ^TestDone$ ./tests

# Тест удаления задач
go test -run ^TestDelTask$ ./tests

# Тест расчета следующих дат
go test -run ^TestNextDate$ ./tests
```

### Настройки тестов

В файле `tests/settings.go` можно настроить следующие параметры:

```go
var Port = 7540        // Порт для тестового сервера
var DBFile = "../scheduler.db"  // Путь к файлу базы данных
var FullNextDate = false        // Расширенная поддержка NextDate
var Search = false              // Поиск по задачам
var Token = ``                  // Токен авторизации
```

**Рекомендуемые настройки для тестов:**
- `Port = 7540` - порт должен совпадать с основным сервером
- `DBFile = "../scheduler.db"` - путь к тестовой базе данных
- `FullNextDate = false` - базовая поддержка NextDate
- `Search = false` - поиск не реализован
- `Token = ""` - авторизация не требуется

## API Endpoints

### Основные операции с задачами:

- **GET** `/api/tasks` - получить список всех задач
- **POST** `/api/task` - создать новую задачу
- **GET** `/api/task?id=<id>` - получить задачу по ID
- **PUT** `/api/task` - обновить существующую задачу
- **DELETE** `/api/task?id=<id>` - удалить задачу
- **POST** `/api/task/done?id=<id>` - отметить задачу как выполненную

### Примеры использования API:

**Создание задачи:**
```bash
curl -X POST http://localhost:7540/api/task \
  -H "Content-Type: application/json" \
  -d '{
    "date": "20240131",
    "title": "Встреча с командой",
    "comment": "Обсуждение планов",
    "repeat": "d 7"
  }'
```

**Получение списка задач:**
```bash
curl http://localhost:7540/api/tasks
```

**Выполнение задачи:**
```bash
curl -X POST http://localhost:7540/api/task/done?id=123
```
